# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - Unreleased

### Added

- Expanded documentation for architecture, testing strategy, reporting, and safety model.
- Added sample suite, request, config, console, and report examples.
- Added xUnit test project for core framework behavior.
- Added CI workflow for restore, format check, build, test, and dry-run validation.
- Added GitHub issue and pull request templates.

### Changed

- Improved README structure for technical review and portfolio readiness.
- Added JSON field and HTTP status assertion support.
- Added REST path template rendering.
- Added stricter config and suite validation.

## [0.1.0] - Initial Public Release

### Added

- Initial API assurance framework structure.
- Suite-based test execution concept.
- SOAP/REST test organization.
- Dry-run validation.
- Risky operation guard.
- HTML, JSON, and CSV reporting.
- MIT license and security policy.
